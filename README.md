# 📧 ML-based Spam Email Detector

A **Machine Learning** project that detects spam emails in real-time.  
Trained on CSV data using **TF-IDF** for text features and **Logistic Regression** for classification.  
Deployed with **Flask** for easy API-based predictions.

---

## 🛠️ Tech Stack
- Python
- scikit-learn
- Pandas
- Flask
- TF-IDF & Logistic Regression

---

## ⚡ Features
- Real-time spam detection via Flask API
- Simple and lightweight ML model
- Works with CSV email datasets
